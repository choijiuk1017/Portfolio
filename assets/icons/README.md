# Icon sources

- `python.svg`: [Devicon Python original](https://github.com/devicons/devicon/blob/master/icons/python/python-original.svg).
- `pytorch.svg`: [Devicon PyTorch original](https://github.com/devicons/devicon/blob/master/icons/pytorch/pytorch-original.svg).
- Devicon assets are provided under the MIT license included in `DEVICON-LICENSE.txt`. Product names and logos belong to their respective owners.
- `codex.png`: the icon supplied by OpenAI's [official Codex IDE extension](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt), downloaded from its publisher CDN.

- `gemma.png`: Gemma family logo from Google's official documentation: https://ai.google.dev/gemma/images/gemma_sq.png (https://ai.google.dev/gemma/docs). Used to identify Gemma 4; the artwork is the shared Gemma mark.
- `blueprint.svg`: vector recreation based on the user-provided Unreal Blueprint Class icon reference.
- `llava-onevision.svg` and `rag.svg`: plain text labels identifying LLaVA and RAG; not official product logos.
